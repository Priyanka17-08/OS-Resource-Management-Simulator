An interactive Operating Systems simulator built with **Python and Streamlit** to explore and understand core OS concepts through visual demonstrations.

## ✨ Features

- **CPU Scheduling:** Explore different CPU scheduling algorithms.
- **Memory Management:** Understand memory allocation techniques.
- **Deadlock Avoidance:** Simulate Banker's Algorithm.
- **Disk Scheduling:** Visualize disk scheduling algorithms.
- **Interactive Dashboard:** Experiment with inputs and observe results.

## 🛠️ Tech Stack

- Python
- Streamlit
- HTML & CSS
- Git & GitHub

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/OS-Resource-Management-Simulator.git
```

### 2. Navigate to the Project

```bash
cd OS-Resource-Management-Simulator
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate it:

**Windows:**
```bash
venv\Scripts\activate
```

**Mac/Linux:**
```bash
source venv/bin/activate
```

### 4. Install Dependencies

```bash
python -m pip install -r requirements.txt
```

### 5. Run the Application

```bash
python -m streamlit run dashboard.py
```

Open the local URL displayed in your terminal.
